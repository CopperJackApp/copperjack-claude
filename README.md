# CopperJack

CopperJack Core connects your assistant to saved CopperJack information. Review property details, understand calculations, compare estimated and recorded costs, inspect Ledger entries, review tasks and notes, and discuss the templates your organization makes available. Document access lists file metadata only.

Connect your CopperJack account when the host requests sign-in. Access follows your existing organization permissions. The plugin reads saved information and cannot change your records.
